超！アルバム Android 版 使い方マニュアル

（アプリの版: Android 版 v17　2026-11-03 作成）


ホーム画面のアイコン

超！アルバムは、1 ページに写真・文字・手書き・線・矢印・日付を好きな所に置いて、自分だけのアルバムを作るアプリです。 作ったアルバムは、画像や PDF にして送ったり、Google ドライブに自動で保存したりできます。iPhone・iPad の Web 版ともデータの形が同じです。

  • 写真の中の「写真」（海・花・夕日・ケーキ）は、説明のために作った絵です。
  • 画面は Galaxy の写真です。ほかのスマホでも、ボタンは同じです。

まず「1. アプリを入れる」から「4. ページを作る」まで読めば、すぐに使えます。

1. アプリを入れる

このアプリは Google Play（アプリのお店）には出していません。 アプリのファイル（FreeAlbum_v17.apk）をスマホに入れて、自分でインストールします。

  1. APK のファイルを、LINE・メール・Google ドライブなどでスマホに送ります。
  2. スマホで FreeAlbum_v17.apk をタップします。
  3. 「このソースからのアプリのインストールは許可されていません」のような表示が出たら、「設定」→「この提供元のアプリを許可」を ON にして、前の画面に戻ります。
  4. 「インストール」（前の版が入っているときは「更新」）を押します。
  5. 「Play プロテクト」の注意が出たら、「詳細」→「インストールする」を選びます。
  6. ホーム画面に「超！アルバム」のアイコンが出れば完了です。
  • くわしくは、別の冊子「Android スマホにアプリ（APK）を入れる方法（LINE で受け取る）」を見てください（例は超！手書きですが、やり方は同じです）。
  • 更新しても、今までのアルバムは消えません。 アンインストールすると消えるので、その前に「9.」か「10.」で保存してください。

2. アルバムを作る


一覧の画面（いちばん最初の画面）

新しいアルバムの名前
  1. 右上の「＋ 新しいアルバム」を押します。
  2. アルバムの名前（例:「夏の家族旅行」）を入れて「決定」。名前は空のままでもよく、そのときは今日の日付の名前になります（あとから変えられます）。
  3. アルバムの画面になります。

一覧の画面でできること


アルバムを長押ししたとき

右上の「︙」
  • アルバムの絵をタップすると、アルバムを開きます。
  • アルバムを長押しすると: 開く／送る・保存する（PDF で LINE・Gmail・ドライブなど）／名前を変える／削除する。
  • 右上の「︙」: 保存・バックアップ（Google ドライブ）。
  • いちばん下の「クラウド: …」は、Google ドライブへの保存の様子です（「自動保存 OFF」は自動保存をしていない）。

3. アルバムの画面


アルバムの画面（2 ページ）

「＋ ページを足す」

ページを長押ししたとき
  • 右上の「＋ ページを足す」で、ページの形（縦長（A4 の形）／横長（A4 の形）／正方形）を選んで、新しいページを作ります。
  • ページの絵をタップすると、そのページを開きます。
  • ページを長押しすると:
メニュー すること
開く ページを開く
送る・保存する このページを画像や PDF で送る（「8.」）
複製する（すぐ後ろに足す） 同じページをもう 1 枚作る
前へ動かす・後ろへ動かす ページの順番を変える
削除する ページを消す
  • 上のアルバムの名前をタップすると、名前を変えられます。左上の「＜」で一覧に戻ります。

ページを開いたら、左上の「編集中」になっていることを確かめます（「閲覧中」のときは、右下の「✎ 編集する」を押します）。


編集中のページ

写真を入れる


「写真」を押したところ
  1. 「写真」を押します。
  2. 「カメラで撮る」または「写真を選ぶ（何枚でも）」。写真を選ぶ画面では、何枚でもまとめて選べます。 - 「入れたらすぐ切り抜く: する／しない」を「する」にすると、写真を入れるたびに切り抜きの画面が出ます。 - 横長のページでは、写真を選ぶ間だけ画面が縦向きになります。
  3. 写真がページに並びます。指で動かしたり、角の青い丸で大きさを変えたりできます（「5.」）。

文字・日付を入れる


「文字を入れる」

「日付・時刻を入れる」
  • 「文字」を押して、文字を入れたい所をタップ → 文字を入れて「決定」。
  • 「＋ 今日の日付」「＋ 今の時刻」で、日付や時刻を足せます。
  • キーボードのマイクを押すと、声で入れられます。
  • 「白い縁取り」にチェックを入れると、写真の上でも読みやすくなります。
  • 「日付」を押すと、「2026年11月3日(火)」「13:54」「2026/11/03」「11月3日」などから選べます。入れたあと「選ぶ」で好きな所へ動かします。

手書き・線・矢印

  • 「手書き」「線」「矢印」を押して、ページの上を指でなぞります。色の丸で色を、「太さ」で太さを先に選んでおきます。
  • まちがえたときは、上の「↶ 戻す」で 1 つ前に戻せます（「↷ やり直す」で戻したのを取り消し）。
ページは自動で保存されます。保存ボタンはありません。左上の「＜ 一覧」でアルバムの画面に戻ります。

5. 置いたものを動かす・直す

「選ぶ」を押してから、置いたものをタップすると、青い点線の枠が出て、上にボタンが並びます。


写真を選んだところ

写真を切り抜く

囲んでまとめて選ぶ（3 個）

指でする操作

  • 枠の中をなぞると、動きます。
  • 右下の青い丸をなぞると、大きさと向きが変わります。
  • 2 本指で広げる・縮める・回すと、大きさと向きが変わります。
  • 重なっているものは、すばやく 2 回タップすると、奥のものを選べます。
  • 何もない所から四角く囲むようになぞると、囲んだものをまとめて選べます。

上に出るボタン

ボタン すること
削除 選んだものを消す
複製 同じものをもう 1 つ作る
前へ・後ろへ 重なったときの上下を入れかえる（まとめて選んだときは「一番前へ」「一番後ろへ」）
切り抜く 写真の要らない所を切る
枠をつける／なくす 写真に白い枠をつける
文字を直す・帯をつける 文字を書き直す／文字の後ろに色の帯をつける
縁をつける／なくす 文字や線に白い縁取りをつける
まっすぐ 回したものを、まっすぐに戻す
  • ボタンが画面に入りきらないときは、ボタンの段を左右になぞると続きが見えます。
  • 選んでいるときに色の丸を押すと、選んだ文字や線の色が変わります。

写真を切り抜く

  1. 写真を選んで「切り抜く」。
  2. 黄色い角や辺を引っぱって、残す所を決めます。下の「自由」「正方形」「4:3」「3:4」「16:9」「元の写真」で形を決められます。
  3. 「決定」（「やめる」で切り抜かずに戻る）。切り抜きの画面は、スマホを横にすると横向きになります。

横長のページ

  • 横長のページは、開くと自動で横向きの画面になります（縦長・正方形のページは縦向き）。スマホを横にして使ってください。

7. 背景の色を変える


右上の「︙」

背景の色（紙の色）

黄色にしたページ
  1. ページを開いて、右上の「︙」→「背景の色（紙の色）を選ぶ」。
  2. 白・クリーム・クラフト紙・黄色・桃色・水色・うす緑・うす紫・灰色・紺・深緑・黒から選びます。 - 「このアルバムの全ページをこの色にする（これから足すページも）」にチェックを入れてから選ぶと、アルバムの全部のページが同じ色になります。

8. 送る・保存する（画像・PDF）


ページの「送る」

1 ページを送る

ページの「送る」（または「︙」→「送る・保存する」、アルバムの画面でページを長押し →「送る・保存する」）。

選ぶもの すること
画像で送る LINE などで、開いてすぐに見える
PDF で送る 拡大してもきれい。印刷したいときに
アルバム全部を 1 つの PDF で送る そのアルバムの全部のページが 1 つの PDF になる
画像にして、スマホの写真アプリに保存 ページを画像にして、写真アプリ（ギャラリー）に入れる
  • 送るときは、次に送り先（LINE・Gmail・ドライブなど）を選ぶ画面が出ます。

アルバムを丸ごと送る

一覧の画面でアルバムを長押し →「送る・保存する（PDF で LINE・Gmail・ドライブなど）」。

9. バックアップを取る・戻す（ファイル）

準備なしで、全部のアルバム（ページと写真）を 1 つのファイル（zip）にまとめて保存できます。


「保存・バックアップ」の画面のいちばん上

バックアップを取る

  1. 一覧の右上の「︙」→「保存・バックアップ（Google ドライブ）」。
  2. 「書き出す（バックアップを取る）」。
  3. 保存先の画面で、左上の「≡」→「ドライブ」を選ぶと Google ドライブに入ります。「保存」。
  • zip の中には、アルバムごとの見る用の PDF も入っています。写真が多いと、ファイルが大きくなります。
  • 「最後に書き出した日時」で、いつバックアップしたか分かります。

バックアップから戻す

  1. 「保存・バックアップ」→「読み込む（バックアップから戻す）」。
  2. 保存した zip ファイルを選ぶ →「戻す」。 - 今あるアルバムは消えません（ないページを足します）。 - iPhone・iPad の Web 版で書き出したファイルからも戻せます（逆も）。

10. 自動でクラウド（Google ドライブ）に保存する

準備をすると、ページを書き終えて一覧に戻るたびに、自分の Google ドライブの「超！アルバム」フォルダへ自動で保存します。アルバムごとに、全部のページをまとめた PDF（名前はアルバムの名前）が入ります。


URL と合言葉を入れる所

はじめての準備

スクリプトの準備（はじめてのときだけ・パソコンがおすすめ）

超！手書きのスクリプトとは別のものです。別のプロジェクトを作ってください。iPhone・iPad の Web 版で準備が済んでいれば、同じ URL と合言葉を入れるだけで使えます。
  1. パソコンのブラウザで https://script.google.com/ を開き、「新しいプロジェクト」を作ります（名前は「超！アルバム保存」など）。
  2. 版のフォルダの「Code.gs（Google Apps Script に貼るもの）.txt」をメモ帳で開いて全部コピーし（スマホでは画面の「スクリプトをコピー」）、最初からある文と入れ替えて貼り、保存します。
  3. 左の歯車（プロジェクトの設定）→ いちばん下の「スクリプト プロパティを追加」→ プロパティに PASSWORD、値に好きな合言葉 →「スクリプト プロパティを保存」。
  4. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」→ 次のユーザーとして実行「自分」、アクセスできるユーザー「全員」→「デプロイ」。
  5. 「アクセスを承認」→ 自分のアカウント →「詳細」→「（安全ではないページ）に移動」→「許可」。自分で作ったスクリプトなので心配いりません。
  6. 出てきたウェブアプリの URL（https://script.google.com/macros/s/…/exec）をコピーして、メールや LINE で自分のスマホに送ります。

アプリに入れる

  1. 「保存・バックアップ」の「ウェブアプリの URL」の欄を長押し →「貼り付け」。
  2. 「合言葉」の欄に、PASSWORD と同じ合言葉を入れます。
  3. 「書き終えたら自動でクラウドに保存する」にチェックを入れます。
  4. 「保存して、つながるか試す」。「つながりました」と出れば完了です。
  5. 今までのアルバムもすぐ送りたいときは「今すぐ全部をクラウドに保存」。

Google ドライブに保存されるもの

場所 中身
マイドライブ ＞ 超！アルバム アルバムの名前の PDF（見る用。例: 旅行.pdf）
超！アルバム ＞ 復元用データ アプリに戻すためのデータと写真。さわらないでください
超！アルバム ＞ 消したもの アプリで消したページ・アルバム（クラウドからは消えません）

スマホを替えたとき

  • 新しいスマホにアプリを入れ、同じ URL と合言葉を入れてから「クラウドから戻す」→「戻す」。写真もいっしょに戻すので、Wi-Fi のときがおすすめです。

11. 困ったときは

こんなとき どうする
まちがえて動かした・消した 上の「↶ 戻す」
見ているだけなのに動いてしまう 「編集中」を押して「閲覧中」にする
拡大したまま戻らない 「画面に合わせる」、または 2 回トントンとタップ
奥の写真が選べない すばやく 2 回タップする。または上のものを選んで「後ろへ」
横長のページが縦向きで出ない 横長のページは横向きで使います。縦長のページを作るときは「縦長（A4 の形）」を選ぶ
「つながりませんでした。合言葉が違います」 スクリプト プロパティの PASSWORD と同じか確かめる（大文字・小文字、空白に注意）
「答えが読めません。URL が正しいか…」 URL が /exec で終わっているか、デプロイの「アクセスできるユーザー」が「全員」か確かめる
超！手書きの URL を入れてしまった 超！アルバム用のスクリプトは別です。「10.」の準備をする

12. 言葉の説明

言葉 意味
APK（エーピーケー） Android のアプリのファイル。タップするとインストールできる
Google ドライブ Google の、インターネット上のファイル置き場（無料で 15GB）
クラウド インターネット上の保存場所。ここでは自分の Google ドライブのこと
Google Apps Script（GAS・ガス） Google が無料で用意している、小さなプログラムを動かすしくみ。アルバムを Google ドライブに保存する係
デプロイ 作ったスクリプトを、アプリから使えるように公開すること
URL インターネット上の住所。https:// から始まる文字の並び
合言葉（PASSWORD） 自分だけがスクリプトを使えるようにするための暗号。人に教えない
PDF 見た目をそのまま保つファイル。どの機械でも同じように見え、印刷もできる
zip（ジップ） たくさんのファイルを 1 つにまとめたファイル

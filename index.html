INSTALL GUIDEアプリの入れ方

ANDROID / APK

Android スマホ

  1. 上の DOWNLOAD を押す（「ファイルをダウンロードしますか？」には「ダウンロード」）
  2. ダウンロードが終わったら「開く」を押す
  3. 「提供元不明のアプリ」の表示が出たら「設定」→「この提供元のアプリを許可」を ON にして戻る
  4. 「インストール」（前の版があるときは「更新」）
  5. 「Play プロテクト」の注意が出たら「詳細」→「インストールする」
IPHONE / IPAD

iPhone・iPad

  1. Safari で ACCESS を押して Web 版を開く
  2. 下（iPad は上）の 共有のボタン（□ に ↑）を押す
  3. 「ホーム画面に追加」→「追加」
  4. ホーム画面のアイコンから開くと、全画面で使えます
WEB / ANDROID

Android で Web 版

  1. Chrome で ACCESS を押して Web 版を開く
  2. 右上の「︙」を押す
  3. 「ホーム画面に追加」→「インストール」

Android では、ふつうは APK 版のほうが便利です。

APK のアプリは Google Play（アプリのお店）には出していないので、入れるときに注意の表示が出ます。このページからダウンロードしたものなら、そのまま進めてください。
データはスマホ（ブラウザ）の中に保存されます。大事なメモやアルバムは、ときどきバックアップを取ってください（マニュアルの「バックアップ」の章）。

超！声でスケジュール

VOICE SCHEDULE

超！付箋電卓

STICKY NOTE CALCULATOR

計算した数字を付箋にして貼っておき、あとで足したり計算に使ったりできる電卓です。広告は出ません。

  • 数字の欄を上に引っぱると付箋に。付箋を欄へ戻すと計算に使える。付箋の計算式もあとで見られる

  • 消費税（10%・8%）の税込・税抜、円・ドル・ユーロをその日のレートで

超！画面翻訳

SCREEN TRANSLATOR

画面を四角く囲むだけで、英語を日本語に。Claude Code の PowerShell の画面に出てくる英語の文を、かんたんに翻訳できる Windows ソフトです。いろいろなホームページで英語が出てきたときなどにも使えます。

  • マウスで囲むと、数秒で日本語訳と原文を表示
  • 常駐させれば、Ctrl + Alt + T でいつでも囲める
  • 訳と原文を、西暦の日付と時間つきで自動で履歴に保存。検索もできる

INSTALL GUIDEアプリの入れ方

ANDROID / APK

Android スマホ

  1. 上の DOWNLOAD を押す（「ファイルをダウンロードしますか？」には「ダウンロード」）
  2. ダウンロードが終わったら「開く」を押す
  3. 「提供元不明のアプリ」の表示が出たら「設定」→「この提供元のアプリを許可」を ON にして戻る
  4. 「インストール」（前の版があるときは「更新」）
  5. 「Play プロテクト」の注意が出たら「詳細」→「インストールする」

写真つきの説明: APK の入れ方（PDF）

超！声でスケジュールは、Android のスマホでは Web 版ではなく Android 版を使ってください（理由）。

IPHONE / IPAD

iPhone・iPad

  1. Safari で ACCESS を押して Web 版を開く
  2. 下（iPad は上）の 共有のボタン（□ に ↑）を押す
  3. 「ホーム画面に追加」→「追加」
  4. ホーム画面のアイコンから開くと、全画面で使えます
WEB / ANDROID

Android で Web 版

  1. Chrome で ACCESS を押して Web 版を開く
  2. 右上の「︙」を押す
  3. 「ホーム画面に追加」→「インストール」

Android では、ふつうは APK 版のほうが便利です。

WINDOWS

Windows パソコン

  1. 超！画面翻訳の DOWNLOAD を押す
  2. ブラウザーに「不審なダウンロードをブロックしました」と出たら、それを押して「不審なファイルをダウンロード」
  3. 保存したファイルをダブルクリックする
  4. 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
  5. 「インストール」を押す

写真つきの説明: ダウンロード時に警告が出たとき／超！画面翻訳のマニュアル

APK のアプリは Google Play（アプリのお店）には出していないので、入れるときに注意の表示が出ます。このページからダウンロードしたものなら、そのまま進めてください。
データはスマホ（ブラウザ）の中に保存されます。大事なメモやアルバムは、ときどきバックアップを取ってください（マニュアルの「バックアップ」の章）。
